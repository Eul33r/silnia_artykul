Czy rok jest przestępny?

Rok zwykły w kalendarzu gregoriańskim ma 365 dni, a rok przestępny 366 – dodatkowy dzień to 29 lutego. Dzięki temu kalendarz nie rozjeżdża się z rokiem tropikalnym, który trwa około \(365{,}2422\) doby.

Reguła

Rok \(r\) jest przestępny, gdy spełniony jest jeden z warunków:

  • \(r\) dzieli się przez \(4\) i jednocześnie nie dzieli się przez \(100\), albo
  • \(r\) dzieli się przez \(400\).

Zapisując to symbolicznie:

\[ \bigl( 4 \mid r \ \wedge \ 100 \nmid r \bigr) \ \vee \ 400 \mid r. \]

Zatem lata \(1900\) i \(2100\) nie są przestępne, natomiast \(2000\) i \(2024\) są.

Kalkulator

Algorytm

Warunki sprawdzamy od najbardziej szczegółowego, dzięki czemu wystarczą trzy proste instrukcje warunkowe i operacja reszty z dzielenia:

\[ \begin{aligned} &\textbf{funkcja } \operatorname{CzyPrzestępny}(r): \\ &\quad \textbf{jeżeli } r \bmod 400 = 0 \textbf{ to zwróć } \text{prawda} \\ &\quad \textbf{jeżeli } r \bmod 100 = 0 \textbf{ to zwróć } \text{fałsz} \\ &\quad \textbf{jeżeli } r \bmod 4 = 0 \textbf{ to zwróć } \text{prawda} \\ &\quad \textbf{zwróć } \text{fałsz} \end{aligned} \]

def is_leap_year(year):
    if year % 400 == 0:
        return True
    if year % 100 == 0:
        return False
    if year % 4 == 0:
        return True
    return False


print(is_leap_year(2024))  # True
