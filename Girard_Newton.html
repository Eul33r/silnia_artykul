Wzory Girarda - Newtona

Liczby \(x, y, z\) spełniają układ równań:

\begin{cases} x + y + z = 1 \\ x^2 + y^2 + z^2 = 2 \\ x^3 + y^3 + z^3 = 3 \end{cases}

Problem:

Ile wynosi suma \(x^4 + y^4 + z^4\) ?

💡 Pokaż wskazówkę 1

Zaskakująco, prawidłową odpowiedzią NIE JEST 4.

💡 Pokaż wskazówkę 2

Wcale nie trzeba rozwiązywać tego układu, tzn. nie jest konieczne wyznaczać ile wynosi każda z liczb \(x, y, z\).

Zacznijmy od zdefiniowania, czym jest wielomian symetryczny.

Otóż wielomian dwóch zmiennych \(f(X, Y)\) nazwiemy symetrycznym, jeśli dla dowolnych \(X, Y\) spełnia warunek: \(f(X, Y) = f(Y, X)\). Czyli tak jakby, jak zamienimy kolejnością zmienne, to nasz wielomian "tego nie poczuje".

Przykład 1:

Wielomian \(f(X, Y) = X^2 + 2XY + Y^2\) jest, jak łatwo się przekonać, symetryczny, bowiem \(f(X, Y) = X^2 + 2XY + Y^2 = Y^2 + 2YX + X^2 = f(Y, X)\)

Przykład 2

Wielomian \(f(X, Y) = X^3 + X^2Y + Y^3\) NIE JEST symetryczny, bo można wskazać takie \(X, Y\) dla których \(f(X, Y) \neq f(Y, X)\), chociażby \(f(2,1) \neq f(1, 2)\)

Analogicznie wielomian trzech zmiennych \(g(X, Y, Z)\) jest symetryczny, jeśli spełnia warunek \[g(X, Y, Z) = g(X, Z, Y) = g(Y, X, Z) = g(Y, Z, X) = g(Z, X, Y) = g(Z, Y, X)\] (Znowu: zamiana kolejnością argumetów "nie nie robi wielomianowi")

Ogólnie: Wielomian \(h\) o \(n\) zmiennych \(X_1, X_2, \cdots X_n\) jest symetryczny, jeśli dla dowolnej permutacji \(\sigma\) (a przypominam: wszystkich takich permutacji jest \(n!\)) zachodzi równość:

\[h(X_{\sigma(1)},X_{\sigma(2)},\cdots X_{\sigma(n)}) = h(X_1, X_2, \cdots, X_n)\]

Symetryczne są m. in. wzory skróconego mnożenia na kwadrat sumy, sześcian sumy, itd.

Symetryczne są także, co ważne(!) wyrażenia postaci:

\(a + b + c + d, ab + ac + ad + bc + bd + cd, abc + abd + acd + bcd, abcd\)

Ogólnie symetryczne są tzw. elementarne wielomiany, nazywane wielomianami Viete'a:

\[W(x_1, x_2, \cdots, x_n) = \sum_{i = 1}^{n} x_i = x_1 + x_2 + \cdots + x_n\] (\(n = \binom{n}{1}\)składników)

\[W(x_1, x_2, \cdots, x_n) = \sum_{1 \leq i < j \leq n} x_i\cdot x_j = x_1\cdot x_2 + x_1\cdot x_3 + \cdots x_{n-1}x_n\] (\(\frac{n\cdot(n-1)}{2} = \binom{n}{2}\) składników złożonych z iloczynu dwóch czynników każdy)

\[W(x_1, x_2, \cdots, x_n) = \sum_{1 \leq i < j < k \leq n} x_i\cdot x_j \cdot x_k = x_1\cdot x_2\cdot x_3+ x_1\cdot x_2\cdot x_4 + \cdots x_{n-1}\cdot x_{n-2} \cdot x_n\] (\(\frac{n\cdot (n-1) \cdot (n-2)}{6} = \binom{n}{3}\) składników złożonych z iloczynu trzech czynników każdy)

\[\cdots\]

\[W(x_1, x_2, \cdots, x_n) = \prod_{i=1}^{n} x_i = x_1 \cdot x_2 \cdot x_3 \cdot \cdots \cdot x_n\] (\(1 = \binom{n}{n}\) iloczyn złożony z \(n\) czynników)
